# Week 13 Spring Security — Student Starter

## Suggested 150-minute class
- 45 min: authentication/authorization, Session/JWT/OIDC, SecurityFilterChain concepts
- 25 min: `step-a-security-basic` — default login & URL authorization
- 35 min: `step-b-db-login` — JPA + MariaDB-backed username/password login
- 10 min: Google OAuth2/OIDC conceptual demonstration (separate prepared instructor demo)
- 35 min: team project planning

Open the **two projects separately** in IntelliJ. Both default to port 8080.

**Student:** Complete TODO comments in Step A SecurityConfig and Step B MemberService / CustomUserDetailsService.

## Database for Lab B
Use your pre-issued external MariaDB account. No Docker/Compose is required. Set DB_URL, DB_USERNAME, DB_PASSWORD in IntelliJ. See `step-b-db-login/README.md`.
